# Post-1999 26 playable-candidate closeout

Date: 7 September 2026

## Outcome

There is now one locally launchable worldwide candidate for every season from
2000/01 through 2025/26. The set contains 25 source-backed post-1999 runtime
assemblies plus the existing 2015/16 worldwide release. Run the complete local
contract check with:

```bash
./pm99-season validate all
```

Launch any season without locating its revision directory:

```bash
./pm99-season play 2000-01
./pm99-season play 2025-26
```

The preferred revisions are declared in `scripts/pm99_season_play_v1.py`.
`./pm99-season play SEASON --print-command` prints the resolved local Wine
command without launching it.

- All 25 have complete runtime game trees containing MANAGPRE, JUG, EQ, ENT
  and all three rendered kit archives.

## Honest evidence boundary

This closes the compiled, locally launchable **playable-candidate** milestone.
It does not promote all 26 seasons to editorially final releases. Genuine
in-game Stoke screenshots already exist for 2000/01, 2001/02 and 2015/16. The
remaining seasons still require the serial remote runner route and screenshot
collection before they can claim the stronger runtime-proved release status.
Editorial queues—especially foreign manager history, recent kit visual review
and ambiguous transfer ownership—remain measurable package data and can be
corrected without changing unrelated records.
