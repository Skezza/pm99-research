# Nationality and detailed-position evidence

The explicit `uefa-player-roster-table-pdf-v1` source family admits a unique
named player row from a retained UEFA handbook. It binds the original PDF,
successful capture receipt, reproducible text extraction, club-table heading,
full name and birthday. Nationality comes from the labelled nationality column;
height and joining year are parsed for context and are never edited by this path.

A separate opt-in policy admits a published detailed profile position. It joins
the exact numeric provider ID, given/family-name crosswalk and birthday to the
retained annual row and original fixture participant. Indexed search-result
captures are labelled as indexed text, never as original HTTP profile bodies.
The existing role taxonomy supplies the native code.

Only the primary fine-role byte changes. The other five role bytes, nationality,
birthday, broad position, ratings, ownership, orders, tactics and images stay
exact. This source-backed policy does not consult or weaken the older factory
identity guard, change its default role mapping, or assert that a current profile
proves a particular opening-day tactical position.

Requests and source bindings carry the player, club and year. No player-specific
or season-specific exception is embedded in the provider. Optional source facts
with conflicting values remain unchanged and documented.

Credits: UEFA media handbooks and Transfermarkt indexed player profiles.
