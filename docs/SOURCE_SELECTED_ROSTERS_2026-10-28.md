# Positive source roster selection

The existing `season_profile_assignment_pruning_layer_v1.py` now has an opt-in
`source-selected-target-season-roster-v1` policy. The original duplicate-reserve
policy and its source requirements are unchanged.

This policy selects a source-supported squad instead of treating every inherited
seed player as a historical identity that needs individual negative research.
It does **not** prove that an omitted player retired, belonged elsewhere, or was
a duplicate. Such findings require their own evidence and receive separate
checklist dispositions.

Each explicit case pins the registered parent, current package's original
preallocation, exact source selector, requested native player IDs to omit, and
any additional decision evidence. Preparation reopens the revisioned source
intake and reparses its original annual roster, the actual original opening
report, and profiles used for first-fixture additions. Numeric first-XI identity,
published name and DOB bindings must agree with the current native records.

The writer requires all eleven sourced starters and at least sixteen active,
source-supported survivors. It can omit only explicitly requested flag-zero
whole-actor seed links. It cannot omit a positively supported actor or an
explicit recipe starting-XI/substitute selection. Surviving flag-one rows remain
opaque and byte-identical; other flag values are refused. No flag semantics are
inferred.

Only the selected EQ roster rows/counts and required indexed offsets change.
Every JUG byte, player object, portrait, retained row, unrelated club, manager,
kit and tactic is preserved. Unrostered seed objects remain declared as preserved
native records; their continued presence is not an active squad-membership claim.
The package carries the source plan and refuses factory compilation that would
discard the layer. SOURCE rebuild uses the existing assignment reconstruction
route and independently reproduces the recipe and game.

The receipt records `source_roster_selection_case_ids` and explicit omitted IDs;
`fixed_duplicate_case_ids` is empty. Neither a search failure nor a selection
omission closes a duplicate or historical ownership case.

Initial controlled evidence concerns Valencia 2023/24. Its positive source cohort
has seventeen active players plus two source-backed opaque links. Five inherited
flag-zero seed links can be omitted while all eleven original starters survive.
The separate official LALIGA retirement evidence establishes the Cañizares bug;
the other four omissions are source selections, not four newly certified bugs.
Preparation and a native dry run are not installation or runtime certification.
The release checklist and CURRENT_WORK.md record delivery separately.
